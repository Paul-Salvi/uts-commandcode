// PRIORITY ISSUES
P0

Primary CTA labels fail contrast

Every bg-accent button uses text-ink (white on #5dcaa5, ≈2:1); every bg-signal button uses white on #0e9488 (≈3.7:1). These are the main actions: Upload models, Generate now, Initiate delivery, Sign in, Create Sponsor, Get early access.

FIX: Darken the label to the existing --on-signal ink (#062622) or deepen both roles toward a 4.5:1 pair. /design recolor.
P1

Clickable rows have no keyboard path

ModelsTable, DeliveryRunsList, and the sponsor-group rows are <tr onClick> with no tabIndex, role, or key handler.

FIX: Make each row a real link or add tabIndex + role="link" + Enter/Space handling, or move the action to an accessible affordance. /design interaction.
P1

Modals have no focus management

ModalShell (ConfirmDialog, ModelDetailModal, ImportResultModal, sponsor forms) sets role="dialog" aria-modal and closes on Escape, but never moves focus in, traps it, or restores it to the trigger.

FIX: Focus the dialog on open, trap Tab within it, restore focus to the opener on close. /design interaction.
P2

Focus indication is border-only

All inputs/selects (LoginForm, ModelsTable, SponsorsOverview, FileFormatConfigWizard, etc.) use outline-none with only focus:border-signal.

FIX: Replace with a visible ring: focus-visible:ring-2 ring-signal ring-offset-2. /design interaction.
P2

Inputs below 16px trigger iOS zoom

Every text input and select across the app is text-sm (14px) or text-[13px], including login, search, and sponsor config forms.

FIX: Set form controls to at least 16px on screens under 640px (text-base sm:text-sm pattern). /design responsive.
P2

Internal labels in user-facing chrome

Page breadcrumbs read "VERTICAL 1 · DATA IMPORTS", "VERTICAL 2 · SPONSOR & DELIVERY CONFIG", "VERTICAL 3 · DISTRIBUTION SERVICE".
